# Станция Ноль: Протокол ЭХО

Сюжетная 2D-игра для 7 класса. Мира спускается на закрытую станцию метро, чтобы найти друга. Вместе с ремонтным роботом Байтом она возвращает питание, обходит охранных дронов и восстанавливает команды эвакуации. Учебная программа охватывает причастие и образование и употребление деепричастий.

В репозитории готовится предпроектная документация. Игровую сборку предстоит сделать. Первая реализационная задача — фрагмент «Последний поезд» в браузере.

Материалы исследования и план разработки находятся в [ветке `codex/echo-preproduction`](https://github.com/darrriakurochka21092019/igra/tree/codex/echo-preproduction/docs).
