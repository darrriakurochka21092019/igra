# Станция Ноль: Протокол ЭХО

Браузерная 2D-игра для 7 класса по причастиям и деепричастиям. Мира исследует закрытую станцию метро, освобождает Байта и ищет Даню. Кампания рассчитана на одно занятие. Время прохождения зависит от темпа чтения, исследования и разбора ответов.

| Глава | Что предстоит сделать |
| --- | --- |
| Последний поезд | Найти импульсник, пройти мимо патруля, вернуть питание и освободить Байта. |
| Архив смен | Записать собственное движение, синхронизировать две площадки и восстановить сообщение Дани. |
| Живой выход | Найти Даню, вывести из строя два излучателя, восстановить команду и открыть ручную заслонку. |

В кампании 24 письменных задания из банка (по восемь в каждой главе) и одно устное в финале. В режиме с преподавателем устный ответ подтверждается по критериям. В самостоятельном режиме игрок сверяет объяснение с образцом. Запись голоса доступна по желанию, при поддержке браузера и после разрешения на микрофон. Аудио хранится в памяти до закрытия окна. Прогресс сохраняется в текущем браузере после важных действий. Учебный отчёт можно скачать в CSV.

## Использование на уроке

Чтобы отработать одну тему, выберите главу в разделе «Открыть отдельную главу». У каждой главы свой прогресс и итоговый отчёт. Кнопка «Продолжить» на заставке возвращает к сохранению полной кампании. В отчёте видно, в каких заданиях ученик ошибался, пользовался подсказками или открывал разбор. Темы для повторения также выводятся на экране итогов.

В сохранениях из прежней версии решённые задания и открытые проходы сохраняются. Новые задания появятся на предстоящих терминалах. Чтобы решить весь набор в уже пройденной главе, начните её заново с заставки.

На карте пунктир показывает путь к цели по открытым проходам. В архиве запись сохраняется, когда Мира задерживается на площадке А. После возврата к стойке её можно воспроизвести повторно, в том числе после перезагрузки. Клавиша R и кнопка «Сбросить запись» позволяют записать другой маршрут.

## Запуск

Понадобится Node.js 22.12 или новее.

```bash
npm ci
npm run dev
```

Производственная сборка создаётся командой `npm run build` в `dist/`. Сборку можно открыть через `npm run preview` или разместить на статическом хостинге. После сборки команда `npm run portable` упакует игру в один файл `station-zero.html`. Этот файл можно открыть напрямую в браузере без установки. Сохранения для веб-версии и для локального файла независимы.

**Управление.** WASD или стрелки — движение, Shift — бег, пробел — рывок, E — взаимодействие, левая кнопка мыши или F — выстрел, M — карта, Esc — пауза. На сенсорных устройствах есть экранные кнопки. «Спокойный бой» в настройках облегчает обход дронов и увеличивает время уязвимости излучателей.

## Устройство проекта

- `src/campaign.ts` хранит карты трёх глав и сюжетные вступления. Движение, коллизии, ИИ, оружие и запись движений работают в Phaser.
- `src/learning.ts` использует [банк заданий](content/questions/index.json). Номера вопросов сохранены из предпроектного банка и не обязаны совпадать с номерами игровых глав. Проверка структуры — `python scripts/check_question_bank.py` с установленным `jsonschema`.
- `src/progress.ts` хранит контрольные точки и учебные результаты в localStorage.
- [Сценарий](docs/STORY.md), [учебная программа](docs/CURRICULUM.md), [Art Bible](docs/ART_BIBLE.md) и [реестр ассетов](docs/ASSET_REGISTER.md) описывают исходный замысел. Документы о шести главах относятся к предпроектной версии. Текущий выпуск использует три главы из таблицы выше.

В игре использован Phaser, распространяемый по MIT. [Текст лицензии](public/PHASER-LICENSE.txt).
