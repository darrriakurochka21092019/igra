## Выбранный стек

**Phaser 4.2.1, TypeScript, Vite, Tiled, HTML/CSS поверх игрового canvas и IndexedDB.** У Phaser есть необходимые игровые примитивы. TypeScript позволяет независимо тестировать оценивание и сохранение. HTML-формы дают русскую раскладку, вставку текста, управление фокусом и понятную работу с микрофоном. Пустой `igra` позволяет создать эти модули без переноса проекта. Phaser 3.90.0 рассматриваем как запасной вариант, если одинаковый тест целевых компьютеров покажет несовместимость 4.2.1 и подтвердит исправную работу 3.90.0.

Первая проверка — собрать две комнаты платформы с коллизиями тайлов, анимацией двери, пулом снарядов, одним дроном, вводом русского текста, записью при согласии и восстановлением контрольной точки. Целевые устройства, критерии кадровой частоты и сценарии отказа описаны в [плане тестирования](TEST_PLAN.md). Сначала HTTP localhost, затем статическая сборка по HTTPS и проверка под путём `/igra/`. Нативную упаковку рассматриваем после проверки браузерной версии, если понадобится запуск отдельным приложением.

## Синтез речи и стоимость

| Вариант | Русский язык, условия и применение |
| --- | --- |
| Субтитры и актёрские реплики | Субтитры входят в первую главу и доступны всегда. Для записей нужны авторские исходники и согласованные права на реплики. Стоимость озвучивания зависит от количества реплик и договорённости с исполнителем. |
| [SpeechSynthesis](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis/getVoices) | Браузер выдаёт голоса, доступные на устройстве. Опциональная кнопка чтения вопроса только при доступном локальном голосе `ru-RU`. У API проекта нет тарифа за запрос, выбор зависит от системы. Качество ударений проверяем вручную. |
| [Piper](https://github.com/OHF-Voice/piper1-gpl/blob/main/docs/LICENSING.md) | Есть русские модели, движок GPL-3.0-or-later. Бесплатный локальный запуск, затраты на подготовку и вычитку. Условия модели проверяются по её MODEL_CARD отдельно. Кандидат для предварительно записанных реплик после проверки выбранной модели. |
| [RHVoice](https://github.com/RHVoice/RHVoice/blob/master/doc/en/License.md) | Есть русские голоса. Основная библиотека LGPL-2.1-or-later, конфигурация с MAGE меняет условия распространения. У отдельных голосов отдельные условия, в том числе NC/ND. Кандидат для локального прогона дикции. |

[MediaRecorder](https://developer.mozilla.org/en-US/docs/Web/API/MediaRecorder) относится к записи ответа, [getUserMedia](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia) требует разрешения и защищённого контекста. Речевой движок не участвует в оценивании. Для озвучивания вопросов предпочтение отдаём читаемости, русским ударениям и возможности играть со звуком, полностью отключённым пользователем.
